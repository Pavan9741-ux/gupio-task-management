# Task Management Dashboard

A responsive Task Management Dashboard developed as part of the Gupio Campus Placement Assignment.

## Live Demo

https://pavan9741-ux.github.io/gupio-task-management/

## GitHub Repository

https://github.com/Pavan9741-ux/gupio-task-management

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Task status management
    - To Do
    - In Progress
    - Completed
- Priority management
    - Low
    - Medium
    - High
- Due date selection and validation
- Prevents selecting past due dates
- Search tasks by title and description
- Filter tasks by status
- Dashboard statistics
    - Total Tasks
    - To Do
    - In Progress
    - Completed
- Data persistence using browser LocalStorage
- Responsive user interface
- User-friendly validation and error messages

## Technologies Used
